# سیستم تشخیص اسپم فارسی

اپ جنگو برای تشخیص پیام‌های اسپم فارسی (ایمیل و پیامک) با مدل **Calibrated LinearSVC (نسخه ۳)**.

## دیتاست‌ها (پوشه `data/`)

| فایل | توضیح | تعداد |
|---|---|---|
| `emails.csv` | ایمیل‌های فارسی (تبلیغاتی و شخصی) | ۱٬۰۰۰ |
| `sms_persian.csv` | پیامک‌های واقعی فارسی — تبلیغات، جوایز، اطلاعیه‌های بانکی و… | ۵٬۵۲۳ |
| `extra_patterns.csv` | الگوهای فیشینگ، پیام‌های اداری و اطلاع‌رسانی داخلی (تولیدشده با قالب‌های متنوع) | ~۹۰۰ |

| `similar_patterns.csv` | نمونه‌های هم‌سبک با تست‌های واقعی: فیشینگ، فرار از فیلتر (حروف جدا/فینگلیش/ایموجی)، تله‌های متن سالم | ~۷۶۰ |

مجموع: حدود **۸٬۲۰۰ نمونه**. همه فایل‌های csv داخل پوشه `data/` به‌صورت خودکار ادغام می‌شوند؛ برای افزودن داده جدید کافی است فایل جدیدی با ستون‌های `text` و `label` (spam/ham) اضافه کنید.

> منبع دیتاست پیامکی: [MahdiyarGHD/sms-spam-dataset](https://github.com/MahdiyarGHD/sms-spam-dataset)

## دقت مدل (روی ۲۰٪ داده دیده‌نشده)

| معیار | مقدار |
|---|---|
| Accuracy | **۹۵.۷٪** |
| F1-Score | **۹۶.۱٪** |
| ROC-AUC | ۹۸.۸٪ |

ویژگی‌های نسخه ۳: تشخیص فیشینگ (درخواست اطلاعات کارت/حساب + فوریت)، مقاوم در برابر جداسازی حروف («ب ر ن د ه»)، تشخیص مکاتبات اداری و اطلاعیه‌های داخلی به‌عنوان پیام عادی.

**سیاست هزینه‌محور متعادل:** آستانه تصمیم طوری انتخاب می‌شود که «اسپم‌شدنِ اشتباهی یک پیام عادی» ۲ برابر بیشتر از «رد شدن یک اسپم» جریمه شود — تعادل بین امنیت پیام‌های عادی و بازیابی اسپم. (برای محافظه‌کاری بیشتر، `fp_cost` را در `core.py` افزایش دهید.)

آستانه تصمیم بدون نشت به داده تست (با احتمالات out-of-fold روی داده آموزش) انتخاب می‌شود.

## نصب و اجرا

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

سپس به `http://localhost:8000` بروید.

## رفع مشکلات رایج

**خطای ناسازگاری مدل هنگام تست متن/فایل** (مثلاً `Can't get attribute ...`):
مدل‌های اسکیت‌لرن به نسخه کتابخانه وابسته‌اند. اگر نسخه اسکیت‌لرن شما با نسخه‌ای که مدل با آن ذخیره شده متفاوت باشد، کافی است **یک‌بار از صفحه «آموزش مدل»** آموزش دهید تا مدل با نسخه شما بازتولید شود (حدود ۱ دقیقه).

## بخش‌های اپ

| مسیر | کاربرد |
|---|---|
| `/` | داشبورد: وضعیت سیستم، آمار مدل، ماتریس اغتشاش |
| `/train/` | آموزش مدل با **لاگ زنده و نمایش مراحل** |
| `/test/` | تست تکی متن |
| `/test-file/` | آپلود فایل CSV و ارزیابی گروهی |
| `/api/predict/` | API با فرمت `POST {"text": "..."}` |

## آموزش از خط فرمان

```bash
python train_and_evaluate.py            # همه دیتاست‌های پوشه data
python train_and_evaluate.py --data data/emails.csv   # فقط یک فایل
```

```
├── data/                 # دیتاست‌ها (همه خودکار ادغام می‌شوند)
├── saved_models/         # مدل و متادیتای ذخیره‌شده
├── templates/            # قالب‌های رابط کاربری
└── train_and_evaluate.py # اسکریپت آموزش/ارزیابی خط فرمان
```
