# سیستم تشخیص اسپم فارسی

اپ جنگو برای تشخیص پیام‌های اسپم فارسی (ایمیل و پیامک) با مدل **Calibrated LinearSVC (نسخه ۳)**.

## دیتاست‌ها (پوشه `data/`)

| فایل | توضیح | تعداد |
|---|---|---|
| `emails.csv` | ایمیل‌های فارسی پایه | ۱٬۰۰۰ |
| `sms_persian.csv` | پیامک‌های واقعی فارسی (پاک‌سازی‌شده از ۵۲ برچسب غلط) | ۵٬۵۱۹ |
| `formal_scam_patterns.csv` | فیشینگ رسمی-اداری با بیان متنوع | ~۱٬۱۰۰ |
| `extra_patterns.csv` | فیشینگ/فوریت + هام اداری | ~۹۰۰ |
| `similar_patterns.csv` | هم‌خانواده الگوهای تست واقعی + فرار از فیلتر | ~۷۶۰ |
| `grayzone_fixes.csv` | اعتبار منقضی، وی‌شینگ، همکاری جعلی | ~۴۰۰ |
| `email_phishing_patterns.csv` | فیشینگ ایمیلی برندها | ~۲۸۰ |
| `final_touches.csv` | اصلاحات نهایی + محافظت هام | ~۱۶۰ |
| `ham_balance.csv` + `ham_balance2.csv` | پیام‌های عادی متنوع برای توازن کلاس‌ها | ~۲٬۴۰۰ |
| `finglish_patterns.csv` | فینگلیش و محاوره واقعی | ~۴۵۰ |

مجموع: حدود **۱۲٬۷۰۰ نمونه** با توازن نزدیک ۵۰/۵۰. همه فایل‌های csv داخل پوشه `data/` به‌صورت خودکار ادغام می‌شوند؛ برای افزودن داده جدید کافی است فایل جدیدی با ستون‌های `text` و `label` (spam/ham) اضافه کنید.

> منبع دیتاست پیامکی: [MahdiyarGHD/sms-spam-dataset](https://github.com/MahdiyarGHD/sms-spam-dataset)

## دقت مدل

| تست | Accuracy | Precision | Recall |
|---|---|---|---|
| اعتبارسنجی رسمی (۲۰٪ دیده‌نشده) | **۹۷.۱٪** | ۹۷.۹٪ | ۹۶.۴٪ |
| داده طبیعی ۲۱۷ تایی مستقل | **۹۹.۱٪** | **۱۰۰٪** | ۹۶.۸٪ |
| فایل تست ۵۷ تایی کاربر | **۹۸.۲٪** | ۱۰۰٪ | ۹۸.۱٪ |
| فایل تست ۲۴ تایی کاربر | **۱۰۰٪** | ۱۰۰٪ | ۱۰۰٪ |

ویژگی‌های نسخه ۳: تشخیص فیشینگ (درخواست اطلاعات کارت/حساب + فوریت)، مقاوم در برابر جداسازی حروف («ب ر ن د ه»)، فینگلیش و محاوره، تشخیص مکاتبات اداری و اطلاعیه‌های داخلی به‌عنوان پیام عادی.

**سیاست هزینه‌محور متعادل:** آستانه تصمیم طوری انتخاب می‌شود که «اسپم‌شدنِ اشتباهی یک پیام عادی» ۲ برابر بیشتر از «رد شدن یک اسپم» جریمه شود — تعادل بین امنیت پیام‌های عادی و بازیابی اسپم. (برای محافظه‌کاری بیشتر، `fp_cost` را در `core.py` افزایش دهید.)

آستانه تصمیم بدون نشت به داده تست (با احتمالات out-of-fold روی داده آموزش) انتخاب می‌شود. گزارش کامل: صفحه «ریپورت مدل» در اپ یا `REPORT.md`.

## نصب و اجرا

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

سپس به `http://localhost:8000` بروید. رابط کاربری کاملاً ریسپانسیو است (در موبایل با منوی همبرگری و سایدبار کشویی).

## رفع مشکلات رایج

**خطای ناسازگاری مدل هنگام تست متن/فایل** (مثلاً `Can't get attribute ...`):
مدل‌های اسکیت‌لرن به نسخه کتابخانه وابسته‌اند. اگر نسخه اسکیت‌لرن شما با نسخه‌ای که مدل با آن ذخیره شده متفاوت باشد، کافی است **یک‌بار از صفحه «آموزش مدل»** آموزش دهید تا مدل با نسخه شما بازتولید شود (حدود ۱ دقیقه).

## بخش‌های اپ

| مسیر | کاربرد |
|---|---|
| `/` | داشبورد: وضعیت سیستم، آمار مدل، ماتریس اغتشاش |
| `/train/` | آموزش مدل با **لاگ زنده و نمایش مراحل** |
| `/test/` | تست تکی متن |
| `/test-file/` | آپلود فایل CSV/Excel/TXT و ارزیابی گروهی (تا ۲۰۰۰ ردیف) |
| `/about/` | توضیحات مدل: معماری، سیاست تصمیم، داده‌های آموزشی |
| `/report/` | ریپورت کامل مدل (رندر `REPORT.md`) |
| `/api/predict/` | API با فرمت `POST {"text": "..."}` |

## آموزش از خط فرمان

```bash
python train_and_evaluate.py            # همه دیتاست‌های پوشه data
python train_and_evaluate.py --data data/emails.csv   # فقط یک فایل
```
